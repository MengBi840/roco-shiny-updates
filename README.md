# 洛克精灵册

《洛克王国世界》异色收集追踪 + 全精灵离线图鉴应用。

## 功能

- **异色追踪**
  - 内置 S1–S4 赛季数据（金月/赤月、赛季奇遇/常驻异色），顶部赛季下拉切换，默认 S4。
  - 「解锁模式」开关：开启后点击整行精灵即可解锁/取消（勾选同步、头像切异色形态），状态保存在本地，切换赛季/重启不丢失；顶部实时显示当前分类与赛季总进度。

- **特殊异色（通行证）**
  - 赛季下拉独立「特殊异色」条目，内置 S1–S4 通行证/特殊异色精灵（带来源标签）。

- **本周大量出没**
  - 顶部卡片自动按当前日期高亮本周出没精灵（日期 + 精灵球）；点「查看全部」看完整 S4 出没时间表。

- **全精灵图鉴**
  - 内置 612 条精灵/形态（编号、名称、属性、蛋组、种类、身高体重、总种族值、获取方式、描述、本体立绘）。
  - 名称/编号搜索、属性筛选、蛋组筛选、图鉴顺序/编号升序/编号降序；筛选区可折叠；点击条目查看详情。

- **远行商人**
  - 顶部商人行：当前轮次、今日商品数、**商人离开倒计时**；点击查看今日在售商品（名称/类别/价格/限购）。
  - **缓存近两日记录**（今天/昨天），离线可查，超两天自动清理；今日未获取显示「今日未探索到」。

- **界面**
  - 底部导航「异色追踪 / 精灵图鉴」平级切换；**日/夜主题切换**（右上角 ☀️/🌙）；
  - 清新浅色 / 深色两套外观；全部数据离线可用。

- **更新检测**
  - 右上角 **齿轮 + 红点**：有新版才亮红点，不再自动弹窗；
  - 齿轮面板显示 当前/最新版本、「更新公告」（发布者填写的正文）、一键下载。
