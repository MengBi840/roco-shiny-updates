# 洛克精灵册

《洛克王国世界》异色收集追踪 + 全精灵离线图鉴应用。

## 功能

- **异色追踪**
  - 内置 S1–S4 全部赛季数据（金月/赤月、赛季奇遇/常驻异色分组），顶部赛季下拉切换，默认 S4。
  - 每个精灵可勾选「已解锁」并保存（切赛季/重启不丢失），顶部实时显示当前分类与赛季总进度。
  - 「解锁模式」开关：关闭时只读防误触，打开后点击整行精灵即可解锁/取消，头像同步切换为异色形态。

- **特殊异色（通行证）**
  - 赛季下拉中的独立「特殊异色」条目，内置 S1–S4 通行证/特殊异色精灵（带来源标签）。

- **本周大量出没**
  - 顶部卡片自动按当前日期高亮本周出没精灵（日期 + 精灵球）；点「查看全部」查看完整 S4 出没时间表。

- **全精灵图鉴**
  - 内置 612 条精灵/形态（编号、名称、属性、蛋组、种类、身高体重、总种族值、获取方式、描述、高清立绘）。
  - 支持名称/编号搜索、属性筛选、蛋组筛选、编号升降序；筛选区可折叠；点击条目查看详情。

- **界面**
  - 清新卡通风；底部导航「异色追踪 / 精灵图鉴」平级切换；全部数据离线可用。

- **更新检测**
  - 启动时联网检查 GitHub Releases，发现新版弹窗提示并可一键下载；弹窗中的「更新公告」显示发布者填写的 Release 正文。
